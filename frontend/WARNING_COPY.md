## 조합원 분양가 비율 관련 주의 문구

> **용어 주의** : `0.8` 은 "일반분양가의 80%" 라는 뜻이다.
> **"할인율" 이라고 부르지 않는다** — 할인율이면 0.2(20% 할인)가 되어 정반대로 읽힌다.
> 코드 변수명은 `member_price_ratio`.

### 라벨

```
조합원 분양가 비율 (조합 총회 의결)
현재 값: 일반분양가의 80%
```

숫자 `0.8` 보다 "일반분양가의 80%" 가 바로 읽힌다.

### 슬라이더 아래 상시 문구

```
조합원은 통상 일반분양가보다 10~20% 저렴하게 분양받습니다.
조합 총회에서 정하는 값이라 개인이 바꿀 수 없습니다.
```

슬라이더 범위 : 최소 0.75 / 기본 0.80 / 최대 0.95 (2026-10-03 확정)

### 툴팁

```
조합원 분양가 비율이란

조합원분양가 ÷ 일반분양가 입니다.
조합원은 토지·건물을 내놓고 사업 위험을 함께 지는 대가로
일반분양자보다 싸게 분양받습니다.

조합원분양가는 관리처분계획인가 때,
일반분양가는 입주자모집공고 때 확정됩니다.
두 시점이 1~3년 차이나므로 실제 비율은 시세 변동에 따라 달라집니다.

이 값을 올리면 조합 수입이 늘어 비례율이 함께 오릅니다.
그만큼 권리가액도 커져서 분담금 변화는 크지 않습니다.

## 조합원 평형 배정 관련 주의 문구

> **상태** : 현재 엔진은 "평형 비율대로 균등 배정" 으로 계산한다.
> 아래 문구는 **"큰 평형 우선 배정" 가정으로 바꾼 뒤** 적용한다.

### 왜 필요한가

분담금에는 두 갈래로 평형이 들어온다.

| | 영향 경로 |
|---|---|
| 내가 고른 평형 | 조합원 분양가 → 분담금 (직접) |
| **다른 조합원들이 고른 평형** | 할인 대상 면적 → 조합 수입 → 비례율 → 권리가액 → 분담금 (간접) |

두 번째는 사용자가 인지하기 어렵다. 조합원이 큰 평형에 몰릴수록 할인 면적이 늘어 조합 수입이 줄고, 비례율이 내려가 **모든 조합원의 분담금이 함께 오른다.**

실측 (월계동 40필지·용적률 250%·조합원 150명 기준)

| 조합원 배정 가정 | 주택 분양수입 | 현재 대비 |
|---|---|---|
| 평형 비율대로 균등 (현재) | 2,855억 | — |
| 큰 평형 우선 | 2,805억 | **−50억** |
| 작은 평형 우선 | 2,895억 | +40억 |

−50억은 비례율 약 4.5%p, 분담금 약 2천만원에 해당한다.

### 슬라이더·평형 버튼 아래 상시 문구

```
본인을 제외한 조합원은 모두 큰 평형부터 배정받는다고 가정합니다.
실제 평형 배정은 관리처분 단계에서 권리가액 순으로 정해집니다.
```

### 툴팁

```
왜 다른 조합원의 평형까지 따지나요

조합원은 일반분양자보다 싸게 분양받습니다.
조합원이 큰 평형을 많이 가져갈수록 할인 대상 면적이 늘어
조합 전체 수입이 줄어듭니다.

수입이 줄면 비례율이 내려가고, 권리가액이 줄어
본인이 어떤 평형을 골랐든 분담금이 함께 오릅니다.

조합 설립 전에는 누가 어떤 평형을 받을지 알 수 없어
가장 보수적인 경우(큰 평형 우선)로 계산합니다.
```

### 조건부 경고

| 조건 | 문구 |
|---|---|
| 조합원 수 > 큰 평형 세대수 | `조합원 수가 큰 평형 세대수를 넘어 나머지는 다음 평형으로 배정된다고 가정했습니다.` |
| 조합원 수 ÷ 분양 세대수 > 0.9 | `조합원이 분양 세대의 대부분을 차지해 일반분양 수입이 거의 없습니다. 사업성을 확인하세요.` |

### 값의 성격 표시

```
조합원 평형 배정  →  가정값(보수적). 실제 배정은 관리처분 단계에서 결정됩니다
```

> 임대주택은 분양이 아니라 **지자체·LH 가 매입**한다.
> 도시정비법 제55조제2항 : 공급가격은 공공건설임대주택 **표준건축비**로 하며, **부속토지는 기부채납**한 것으로 본다.
> 단가는 국토부고시 제2023-64호의 층수·전용면적 구간표에서 조회한다.

### 임대동 층수 — 스텝 슬라이더

```
임대동 층수    o────────o────────o────────o
             5층 이하  6~10층  11~20층  21층 이상
                              ▲ 기본
```

전용면적 구간은 임대 1세대 면적에서 자동으로 정해지므로, 사용자가 고르는 건 층수뿐이다.

### 슬라이더 아래 상시 문구

```
층수 구간에 따라 ㎡당 인수 단가가 달라집니다.
오른쪽으로 갈수록 오르는 값이 아닙니다.
```

### 조건부 경고

| 조건 | 문구 |
|---|---|
| 6~10층 선택 | `6~10층이 ㎡당 단가가 가장 높습니다. 엘리베이터·계단실이 필요한데 세대수로 분산되지 않기 때문입니다.` |
| 5층 이하 선택 | `5층 이하는 엘리베이터 설치 의무가 없어 ㎡당 단가가 가장 낮습니다.` |
| 상시 | `임대동을 별동으로 짓는지, 분양동에 섞는지(소셜믹스)에 따라 층수가 달라집니다.` |

### 툴팁

```

재개발로 지은 임대주택은 조합이 파는 게 아니라

표준건축비는 상한가격이며, 층수와 전용면적 구간에 따라 정해집니다.
```

## 예상 분담금 표시 — 명목 + 비율 병기 (2026-10-03 확정)

### 왜 병기하는가

사업기간 슬라이더를 올리면 명목 분담금이 복리로 커진다. 13년이면 7.70억 → 12.78억(1.66배).
그런데 같은 기간 조합원 분양가는 8.99억 → 24.54억(2.73배)이 된다.
**명목 금액만 보여주면 공포를 유발하고, 받는 것 대비 부담이 줄어든다는 사실이 가려진다.**

| 기간 | 명목 분담금 | 조합원 분양가 | 분담금÷분양가 |
|---|---|---|---|
| 0년 | 7.70억 | 8.99억 | 85.6% |
| 13년 | 12.78억 | 24.54억 | **52.1%** |
| 18년 | 14.92억 | 36.11억 | **41.3%** |

현재가치 할인 방식은 쓰지 않는다. 할인율을 2%로 잡으면 1.28배, 8%로 잡으면 0.61배로
**2.7배나 갈려서** 할인율이라는 새 미지수를 또 만들게 된다.
비율 병기는 **모델이 이미 계산하는 두 값의 비**라서 새 가정이 전혀 없다.

### 표시 위치와 문구

```
예상 분담금  (13년 후 기준)
12.78억
선택 평형 분양가 24.54억의 52.1%
```

- "예상 분담금" 레이블 **옆**에 기준 시점 — `(N년 후 기준)`. 사업기간 슬라이더 값을 따른다
- 분담금 **값 아래(옆)** 에 비율 문구

문구 형식 (`" "` 는 변수 자리 표시이며 실제 화면에는 넣지 않는다)

```
선택 평형 분양가 "24.54억"의 "52.1%"
```

### 사업기간 0년일 때

```
예상 분담금  (현재 기준)
```
`(0년 후 기준)` 이 아니라 `(현재 기준)` 으로 쓴다.

### 값의 성격 표시

```
명목 금액입니다. N년 뒤 화폐 기준이므로 오늘 금액과 직접 비교할 수 없습니다.
받는 집값 대비 부담은 함께 표시된 비율로 보세요.
```

```

## 사업 유형 배지 — 재개발 / 재건축 (2026-10-08, 구현됨 — ModelPredictForm.tsx)

### 위치

```
[1] 선택한 필지                    1개  [재건축]
```

- 구역 분석(계산 버튼) 뒤에 뜬다. 필지 선택을 바꾸면 지워지고, 다시 분석하면 새로 판정한다
- 재건축은 보라, 재개발은 초록 배지. 마우스를 올리면 근거가 보인다

### 근거 문구 (툴팁 — 서버 project_type_reason)

| 경우 | 문구 |
|---|---|
| 재건축 | `아파트 단지 필지 N개 (+ 부속지번 M필지)만 선택 (· 국공유·기반시설 K필지는 판정에서 뺌)` |
| 재개발 (섞임) | `아파트 외 필지 N개가 섞여 재개발로 계산` |

## 조합원 분양가 비율 관련 주의 문구 (2026-10-08 개정 — 기본 자동)

> **용어 주의** : `0.49` 는 "일반분양가의 49%" 라는 뜻이다.
> **"할인율" 이라고 부르지 않는다** — 할인율이면 0.51(51% 할인)이 되어 정반대로 읽힌다.
> 코드 변수명은 `member_price_ratio`.
>
> **기본은 자동이다.** 조합은 관리처분계획에서 조합원분양가를 정해 관리처분 비례율을 맞춘다.
> 서버가 관리처분 비례율이 100% 가 되는 비율을 역산하고(`timeline.member_price_ratio`), 사용자가 손잡이를 움직이면 그 값을 쓴다.
> 예전 고정값 0.8(범위 0.75~0.95, "통상 10~20% 저렴" 문구)은 근거가 없고 비례율을 250~300% 로 만들어 폐기했다.

### 라벨 (구현됨 — Slider.tsx)

```
조합원 분양가 비율                 [자동] 일반분양가의 49%
```

손으로 움직인 뒤에는 `[자동]` 대신 `자동으로` 버튼이 나온다 (누르면 다시 자동).

| 자동 | `관리처분 비례율이 100%가 되도록 정한 값입니다. 움직이면 직접 정한 비율로 계산합니다.` |
| 수동 | `직접 정한 비율로 계산 중입니다.` |

### 지표 줄 (구현됨 — 조합원 분양가)

```

```

### 툴팁

```

조합원분양가 ÷ 일반분양가 입니다.
조합은 관리처분계획에서 조합원분양가를 정하면서
비례율(사업이 끝난 뒤 종전자산 1원의 가치)을 맞춥니다.

기본값은 관리처분 비례율이 100%가 되는 비율입니다.
그러면 권리가액이 종전자산 감정가와 같아지고,
개발이익은 낮은 조합원분양가로 모든 조합원에게 고르게 돌아갑니다.

비율을 높이면 비례율이 올라 종전자산이 큰 조합원에게 유리해지고,
낮추면 반대가 됩니다. 조합원 전체가 내는 돈의 합은 같습니다.
```

## 조합원 평형 배정 관련 주의 문구

> **상태** : 현재 엔진은 "평형 비율대로 균등 배정" 으로 계산한다.
> 아래 문구는 **"큰 평형 우선 배정" 가정으로 바꾼 뒤** 적용한다.

### 왜 필요한가

분담금에는 두 갈래로 평형이 들어온다.

| | 영향 경로 |
|---|---|
| 내가 고른 평형 | 조합원 분양가 → 분담금 (직접) |
| **다른 조합원들이 고른 평형** | 할인 대상 면적 → 조합 수입 → 비례율 → 권리가액 → 분담금 (간접) |

두 번째는 사용자가 인지하기 어렵다. 조합원이 큰 평형에 몰릴수록 할인 면적이 늘어 조합 수입이 줄고, 비례율이 내려가 **모든 조합원의 분담금이 함께 오른다.**

실측 (월계동 40필지·용적률 250%·조합원 150명 기준)

| 조합원 배정 가정 | 주택 분양수입 | 현재 대비 |
|---|---|---|
| 평형 비율대로 균등 (현재) | 2,855억 | — |
| 큰 평형 우선 | 2,805억 | **−50억** |
| 작은 평형 우선 | 2,895억 | +40억 |

−50억은 비례율 약 4.5%p, 분담금 약 2천만원에 해당한다.

### 슬라이더·평형 버튼 아래 상시 문구

```
본인을 제외한 조합원은 모두 큰 평형부터 배정받는다고 가정합니다.
실제 평형 배정은 관리처분 단계에서 권리가액 순으로 정해집니다.
```

### 툴팁

```
왜 다른 조합원의 평형까지 따지나요

조합원은 일반분양자보다 싸게 분양받습니다.
조합원이 큰 평형을 많이 가져갈수록 할인 대상 면적이 늘어
조합 전체 수입이 줄어듭니다.

수입이 줄면 비례율이 내려가고, 권리가액이 줄어
본인이 어떤 평형을 골랐든 분담금이 함께 오릅니다.

조합 설립 전에는 누가 어떤 평형을 받을지 알 수 없어
가장 보수적인 경우(큰 평형 우선)로 계산합니다.
```

### 조건부 경고

| 조건 | 문구 |
|---|---|
| 조합원 수 > 큰 평형 세대수 | `조합원 수가 큰 평형 세대수를 넘어 나머지는 다음 평형으로 배정된다고 가정했습니다.` |
| 조합원 수 ÷ 분양 세대수 > 0.9 | `조합원이 분양 세대의 대부분을 차지해 일반분양 수입이 거의 없습니다. 사업성을 확인하세요.` |

### 값의 성격 표시

```
조합원 평형 배정  →  가정값(보수적). 실제 배정은 관리처분 단계에서 결정됩니다
```

## 공공기여 방식 선택 (세부 설정, 2026-10-08)

> 평형 구성 아래 카드. 토지 · 현금 · 공공임대 건축물을 **기부면적 비율(%)** 로 섞는다. 버튼 셋은 비율 프리셋이다.

## 임대 인수수입 관련 주의 문구 (2026-10-08 개정)

> 임대주택은 분양이 아니라 **지자체·LH·SH 가 매입**한다. 두 종류가 단가가 다르다 (2026-10-08 법령 대조로 정정).
> · 재개발 **의무 임대** : 건물값 = **기본형건축비(지상층 + 지하층)의 80%** (시행령 제68조②1, 2025-03-18 시행 · 서울시 조례 제41조①),
>   일반분양 공고일 직전에 고시된 단가. 부속토지는 **감정가**로 받는다.
> · 용적률 **완화분**(도시정비법 제54조) 공공주택 : 건물값 = **표준건축비**, 지하층은 그 63% (법 제55조② 현행 · 서울시 매입기준).
>   부속토지는 **기부채납**(무상). 재건축은 의무 임대가 없어 공공주택 전부가 이쪽이다.
> 단가는 국토교통부 고시 제2026-488호(기본형건축비)·제2023-64호(표준건축비) 표의 층수·전용면적 구간에서 조회한다.

## 예상 분담금 표시 — 명목 + 비율 병기 (2026-10-03 확정)

### 왜 병기하는가

사업기간 슬라이더를 올리면 명목 분담금이 복리로 커진다. 13년이면 7.70억 → 12.78억(1.66배).
그런데 같은 기간 조합원 분양가는 8.99억 → 24.54억(2.73배)이 된다.
**명목 금액만 보여주면 공포를 유발하고, 받는 것 대비 부담이 줄어든다는 사실이 가려진다.**

| 기간 | 명목 분담금 | 조합원 분양가 | 분담금÷분양가 |
|---|---|---|---|
| 0년 | 7.70억 | 8.99억 | 85.6% |
| 13년 | 12.78억 | 24.54억 | **52.1%** |
| 18년 | 14.92억 | 36.11억 | **41.3%** |

현재가치 할인 방식은 쓰지 않는다. 할인율을 2%로 잡으면 1.28배, 8%로 잡으면 0.61배로
**2.7배나 갈려서** 할인율이라는 새 미지수를 또 만들게 된다.
비율 병기는 **모델이 이미 계산하는 두 값의 비**라서 새 가정이 전혀 없다.

### 표시 위치와 문구

```
예상 분담금  (최종 인가 21년 후 · 2047 기준)
13.53억
분양가 77%
```

- "예상 분담금" 레이블 **옆**에 기준 시점 — `(최종 인가 N년 후 · YYYY 기준)`. 분담금은 준공 때 정산되므로 사업기간 슬라이더의 **바깥 손잡이**를 따른다
  (2026-10-07 개정. 예전 `(N년 후 기준)` 은 관리처분 시점 한 점이었다)
- 분담금 **값 아래(옆)** 에 비율 문구

문구 형식 (`" "` 는 변수 자리 표시이며 실제 화면에는 넣지 않는다)

## 작성 규칙

- 한 문장에 하나의 사실만 담는다
- "~할 수 있습니다" 보다 "~합니다" 로 단정한다. 추정이면 "가정값입니다" 라고 명시한다

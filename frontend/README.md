# 1. Overview

**Frontend** 에서는 **React** 사용. (**Vercel** 배포)

- **React, Vite** 를 사용하여 개발.
- **Typescript** 를 사용하여 엄격한 타입 제한과 개발간 디버깅 효율 향상.
- **Tailwind** 를 사용하여 빠르고 간편한 디자인 방식 도입.


# 2. 컴포넌트 종류

- **KakaoMap** : **Kakao SDK API** 를 사용하여 Map 렌더링
- **SideBar** : 사이드바 사용으로 **UI** 상호작용 최적화
- **ModelPredictForm** : 사이드바 내부의 분담금 예측 상호작용 전용 컴포넌트를 사용하여 사이드바 컴포넌트와 책임 분할.
- **Slider** : 예측 상호작용 전용 컴포넌트 내부의 동적으로 생성되는 슬라이드 값들에 대하여 생성되도록 하여 **ModelPredictForm** 컴포넌트와 책임 분할.
- **MapLegend** : **KakaoMap** 위에 주거지역 종류를 띄우는 과정에서, 조금이라도 더 직관적으로 알 수 있게, 가장 위치적으로 적합한 오른쪽 아래 부분에 토글형으로 삽입.

# 3. 추가 정보

- 계층형 컴포넌트 구조를 통하여 추후 유지보수성 향상.
- 평균 이용자 연령대를 고려하여 너무 어둡지 않은, 오히려 밝은 테마 사용.
- 위와 같은 이유로, 평균 이용자 연령대를 고려하여 복잡하게 굳이 필요 없는 회원가입 기능 구현 대신, **Captcha** **v2** 를 도입하여 간편하게 트레픽 관리.
- **Hook** 를 사용하여, 컴포넌트에 대한 역할 책임 분리.
